Both are exported from `astro-icon/components`.

## `<Icon>`

Renders one icon from a build-time collection, resolved at build time.

```ts
interface Props extends HTMLAttributes<"svg"> {
  name: IconName;
  title?: string | { id?: string; value: string };
  desc?: string | { id?: string; value: string };
  size?: number | string;
  width?: number | string | null;
  height?: number | string | null;
}
```

| Prop     | Type                                       | Description                                                                                                              |
| -------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `name`   | `IconName`                                 | `"collection:icon"`, or a bare icon name for a collection named `icons`. Autocompletes against every defined collection. |
| `title`  | `string \| { id?: string; value: string }` | Adds an accessible `<title>`; opts the icon out of its decorative default.                                               |
| `desc`   | `string \| { id?: string; value: string }` | Adds an accessible `<desc>`; opts the icon out of its decorative default.                                                |
| `size`   | `number \| string`                         | Sets `width` and `height` at once; takes priority over either if both are set.                                           |
| `width`  | `number \| string \| null`                 | Defaults to the icon's intrinsic width. Pass `null` to omit the attribute.                                               |
| `height` | `number \| string \| null`                 | Defaults to the icon's intrinsic height. Pass `null` to omit the attribute.                                              |

Plus any global HTML attribute and `aria-*` attribute (forwarded to the rendered `<svg>`), including `aria-label`, `aria-labelledby`, `aria-description`, `aria-describedby`, and `role`.

See [“The `<Icon>` Component”](/guides/components/) for the decorative/labeled accessibility behavior these props drive.

## `<LiveIcon>`

Renders one icon from a live collection, resolved per request.

```ts
interface Props extends HTMLAttributes<"svg"> {
  collection: LiveCollectionName;
  icon: string;
  title?: string | { id?: string; value: string };
  desc?: string | { id?: string; value: string };
  size?: number | string;
  width?: number | string | null;
  height?: number | string | null;
}
```

| Prop                                       | Type                 | Description                                                                                                  |
| ------------------------------------------ | -------------------- | ------------------------------------------------------------------------------------------------------------ |
| `collection`                               | `LiveCollectionName` | The live collection to resolve `icon` from. No bare-name default, unlike `<Icon>`'s `icons` collection.      |
| `icon`                                     | `string`             | The icon's name within `collection`. Always a plain string — resolved per request, not checked at sync time. |
| `title`, `desc`, `size`, `width`, `height` | _(same as `<Icon>`)_ |                                                                                                              |

If the icon fails to resolve, `<LiveIcon>` logs a warning and renders nothing rather than throwing. See [“Live Icons with `<LiveIcon>`”](/guides/live-icon/).
