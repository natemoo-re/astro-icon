Astro Icon is a straightforward icon system for the [Astro](https://astro.build) framework.
This guide assumes that you have an existing Astro project.

See [the Astro installation guide](https://docs.astro.build/en/install/auto/) if you are starting a brand new project.

## Installation

<Steps>

1. Install the `astro-icon` package using your package manager:

   <Tabs syncKey="pkg">
   <TabItem label="npm">

   ```sh
   npm install astro-icon
   ```

   </TabItem>
   <TabItem label="pnpm">

   ```sh
   pnpm add astro-icon
   ```

   </TabItem>
   <TabItem label="Yarn">

   ```sh
   yarn add astro-icon
   ```

   </TabItem>
   </Tabs>

   Astro Icon isn't an Astro integration, so there's nothing to add to `integrations` in `astro.config.mjs`.

2. Define an icon collection in `src/content.config.ts`, the same way you'd define any other [content collection](https://docs.astro.build/en/guides/content-collections/):

   ```ts title="src/content.config.ts"
   import { defineCollection } from "astro:content";
   import { localIcons } from "astro-icon/loaders";

   export const collections = {
     icons: defineCollection({ loader: localIcons() }),
   };
   ```

3. Add your `.svg` files to `src/icons/`:

   <FileTree>
   - src
     - icons
       - logo.svg
       - logos
         - astro.svg
     - content.config.ts
     - pages/
   </FileTree>

4. Render one with the `<Icon>` component:

   ```astro
   ---
   import { Icon } from "astro-icon/components";
   ---

   <Icon name="logo" />
   ```

</Steps>

### Enable autocomplete

Add this line to `src/env.d.ts` so `<Icon name="...">` autocompletes against every icon in your collections, and gives you a type error for a name that doesn't exist:

```ts title="src/env.d.ts" ins="/// <reference path=\"../.astro/astro-icon.d.ts\" />"
/// <reference path="../.astro/astro-icon.d.ts" />
```

This file is generated the first time you run `astro sync`, `astro dev`, or `astro build`, so autocomplete won't show your icons until you've run one of those at least once.

## Quick start

Define a collection in `src/content.config.ts`. Use `createIconLoader` with `iconifyLocalSource` for an [Iconify icon set](https://icon-sets.iconify.design/), or `localIcons` for a directory of your own `.svg` files:

```ts title="src/content.config.ts"
import { defineCollection } from "astro:content";
import { createIconLoader, iconifyLocalSource, localIcons } from "astro-icon/loaders";

export const collections = {
  // Renders any icon from Material Design Icons: <Icon name="mdi:home" />
  mdi: defineCollection({ loader: createIconLoader(iconifyLocalSource("mdi")) }),
  // Renders a local file at src/icons/logo.svg: <Icon name="logo" />
  icons: defineCollection({ loader: localIcons() }),
};
```

Then render an icon with the `<Icon>` component. Both of these are rendered live on this page, from the collections above:

<Showcase code={`---
import { Icon } from "astro-icon/components";
---

<Icon name="mdi:home" size={32} />
<Icon name="logo" size={32} />`}>
  <Icon name="mdi:home" size={32} />
  <Icon name="logo" size={32} />
</Showcase>

`<Icon>` resolves the icon at build time and inlines it as a standalone `<svg>`, with no client-side JavaScript.

## Updating Astro Icon

Astro Icon is a third-party package, not yet supported by `@astrojs/upgrade`. Update it the same way as any other dependency:

<Tabs syncKey="pkg">
<TabItem label="npm">

```sh
npm install astro-icon@latest
```

</TabItem>
<TabItem label="pnpm">

```sh
pnpm add astro-icon@latest
```

</TabItem>
<TabItem label="Yarn">

```sh
yarn add astro-icon@latest
```

</TabItem>
</Tabs>

See the [Astro Icon changelog](https://github.com/natemoo-re/astro-icon/blob/main/packages/core/CHANGELOG.md) for a full list of the changes made in each release. Coming from v1? See [“Upgrading to v2”](/guides/upgrade/v2/).
