## Declare a collection, render an icon

Point a collection at an icon set once, in `src/content.config.ts`:

```ts title="src/content.config.ts"
import { defineIconCollection, iconify } from "astro-icon/collections";

export const collections = {
  mdi: defineIconCollection(iconify("mdi")),
};
```

Then reference any icon in it, from any page. The `name` prop autocompletes against every collection you define, so a typo is a type error at build time — not a broken image in production.

<Showcase code={`---
import { Icon } from "astro-icon/components";
---

<Icon name="mdi:rocket" size={32} />
<Icon name="mdi:heart" size={32} />
<Icon name="mdi:star" size={32} />`}>
  <Icon name="mdi:rocket" size={32} />
  <Icon name="mdi:heart" size={32} />
  <Icon name="mdi:star" size={32} />
</Showcase>

## Bring icons from anywhere

<Tabs>
<TabItem label="Iconify sets">

Install any of [Iconify's](https://icon-sets.iconify.design/) 200,000+ icons and reference them by name.

```ts title="src/content.config.ts"
import { defineIconCollection, iconify } from "astro-icon/collections";

export const collections = {
  mdi: defineIconCollection(iconify("mdi")),
};
```

</TabItem>
<TabItem label="Your own SVGs">

Drop `.svg` files into `src/icons/` and they're picked up automatically, with hot reload in dev.

```ts title="src/content.config.ts"
import { defineIconCollection, localSvg } from "astro-icon/collections";

export const collections = {
  icons: defineIconCollection(localSvg()),
};
```

</TabItem>
<TabItem label="A custom source">

Fetch icons from a design tool, a database, or an internal API by implementing `IconSource`.

```ts title="src/content.config.ts"
import { defineIconSource } from "astro-icon/source";

const mySource = defineIconSource({
  name: "my-source",
  async getIcons(names) {
    /* ...return a Map<string, IconEntry | Error> */
  },
  async listIcons() {
    /* ...return every name */
  },
});
```

</TabItem>
</Tabs>
