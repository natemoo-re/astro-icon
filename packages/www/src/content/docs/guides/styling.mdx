An icon rendered by Astro Icon is an inline `<svg>` in your own markup — not an `<img>`, not an icon font, not a shadow root. There's no styling API to learn, because every icon is already a first-class element in your page's CSS.

## Color

Icons drawn with `currentColor` inherit the CSS `color` of whatever contains them, exactly like text does:

<Showcase code={`<Icon name="mdi:heart" size={32} class="rose" />
<Icon name="mdi:leaf" size={32} class="green" />
<Icon name="mdi:flash" size={32} class="amber" />

<style>
  .rose  { color: #e11d48; }
  .green { color: #16a34a; }
  .amber { color: #d97706; }
</style>`}>
  <Icon name="mdi:heart" size={32} style="color:#e11d48" />
  <Icon name="mdi:leaf" size={32} style="color:#16a34a" />
  <Icon name="mdi:flash" size={32} style="color:#d97706" />
</Showcase>

That also means an icon picks up `color` from a parent for free — inside a link, a button, or a themed section, it just matches:

<Showcase code={`<p class="note">
  <Icon name="mdi:information" /> Heads up — this icon matches its paragraph.
</p>

<style>
  .note { color: #0284c7; }
</style>`}>
  <span style="color:#0284c7;display:inline-flex;align-items:center;gap:0.4rem">
    <Icon name="mdi:information" size={20} /> Inherited from the parent
  </span>
</Showcase>

:::note
This relies on the source SVG using `currentColor` rather than a hardcoded `fill`. Most Iconify sets already do; hand-authored files often don't. If an icon ignores `color`, see [Troubleshooting](/guides/troubleshooting/#an-icon-ignores-css-color).
:::

## Size

`size` sets both dimensions. To size from CSS instead, pass `width={null}` and `height={null}` to drop the attributes entirely, then let `font-size` and `em` units drive it:

<Showcase code={`<Icon name="mdi:star" width={null} height={null} class="scalable" />

<style>
  .scalable {
    width: 1em;
    height: 1em;
    font-size: 3rem;
  }
</style>`}>
  <Icon name="mdi:star" width={null} height={null} style="width:1em;height:1em;font-size:3rem" />
</Showcase>

## Targeting icons with `[data-icon]`

Every rendered icon carries a `data-icon` attribute set to its `name`, so you can style icons without adding a class to each one.

Style every icon on the page:

```astro mark="[data-icon]"
<style>
  [data-icon] {
    width: 1.5rem;
    height: 1.5rem;
    vertical-align: -0.25em;
  }
</style>
```

Or target one specific icon:

```astro mark="[data-icon=\"mdi:heart\"]"
<style>
  [data-icon="mdi:heart"] {
    color: crimson;
  }
</style>
```

## Classes and Tailwind

`<Icon>` forwards `class` (and every other global HTML attribute) straight to the rendered `<svg>`, so utility classes work with no special handling:

```astro mark="class=\"size-6 text-emerald-700\""
<Icon name="logo" class="size-6 text-emerald-700" />
```

See Astro's [Tailwind guide](https://docs.astro.build/en/guides/styling/#tailwind) for adding Tailwind to your project.

## Presentation attributes

Any SVG presentation attribute you pass is set on the rendered `<svg>` and inherited by the icon's inner elements:

```astro
<Icon name="mdi:heart" fill="none" stroke="currentColor" stroke-width={1.5} />
```

Some icon sets redeclare these attributes on their inner elements, which blocks that inheritance — see [Troubleshooting](/guides/troubleshooting/#an-icon-ignores-stroke-width-or-another-presentation-attribute) if a value you pass appears to do nothing.
