Astro Icon is designed to support any of the 150+ open source icon sets distributed by [Iconify](https://iconify.design/).

## Open Source Icon Sets

[Iconify](https://iconify.design/) is a project that distributes normalized packages of open source icon sets. All of these icons are available on-demand in your project through `astro-icon`.

### Find an icon set

Visit the official [Iconify Icon Sets](https://icon-sets.iconify.design/) explorer or the popular [Icônes](https://icones.js.org/) app to browse the available icon sets.

### Using an icon from an icon set

Icon sets can be automatically referenced by their prefixed id, for example:

```astro mark="mdi/account" mark="mdi:account"
---
import Account from 'virtual:icons/mdi/account';
---

<!-- Embed the `account` icon from the `mdi` icon set -->
<Account />
```

### Using multiple icon sources

You are not limited to a single icon source! You may mix and match icon sets.

<Aside type="note">
All icons are injected into your project at build time, so you can use any icon set in your project without having to worry about deployment.
</Aside>
